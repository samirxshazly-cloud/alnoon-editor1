# النون لفهم العلوم — محرر المذكرات التعليمية

نسخة جديدة مبنية من الصفر لتنظيم المذكرات التعليمية داخل صفحات A4 حقيقية مع تحرير مباشر، صور مرتبطة، جداول حقيقية، معادلات كيميائية، حفظ تلقائي، مشاركة، ومساعد Gemini لا يملك صلاحية إعادة كتابة النص الأصلي.

## تشغيل سريع

لا توجد حزم npm خارجية مطلوبة؛ يكفي Node.js 20 أو أحدث.

```bash
node server.js
```

ثم افتح `http://localhost:4173`.

## مبدأ سلامة المحتوى

عند الاستيراد يحتفظ التطبيق بالنص الأصلي كاملًا في `sourceText`. التقسيم المحلي يمر باختبار lossless قبل قبول الاستيراد. عند تشغيل Gemini لا يُسمح للنموذج بإرجاع نص بديل؛ يُرسل إليه كل عنصر مع `id` ويُقبل منه فقط وصف التخطيط/النوع/علاقة العنصر بما حوله. أي تحرير للنص بعد ذلك هو إجراء صريح من المستخدم.

## Gemini BYOK

المستخدم يضع مفتاحه من Google AI Studio في اللوحة الجانبية. المفتاح لا يُكتب في الكود ولا يُحفظ في قاعدة البيانات. افتراضيًا يبقى في sessionStorage فقط؛ الحفظ على الجهاز اختياري وصريح. الطلب يذهب إلى خادم التطبيق عبر HTTPS ثم إلى Google باستخدام `x-goog-api-key`.

الافتراضي هو `gemini-3.7-flash` عبر Interactions API. توجد مسارات توافق لـ Gemini 3.6 Flash و2.5 Flash و2.5 Flash Lite. لا تُستخدم معاملات sampling القديمة مثل temperature/top_p/top_k.

## الحفظ والمشاركة

- IndexedDB في المتصفح: حفظ فوري والعمل دون اتصال.
- خادم Node: مزامنة تلقائية عند توفر الإنترنت.
- رابط مشاركة عشوائي عالي العشوائية يسمح باستكمال تحرير آخر نسخة محفوظة من جهاز آخر.
- عند إعداد Supabase، تنتقل المذكرات والصور إلى تخزين سحابي دائم؛ وإلا يستخدم الخادم مجلد `data/` المحلي.

### إعداد Supabase

1. أنشئ مشروعًا مجانيًا.
2. نفّذ `supabase/schema.sql`.
3. اضبط متغيرات البيئة كما في `.env.example` على الخادم فقط.
4. لا تضع `SUPABASE_SERVICE_ROLE_KEY` في JavaScript أو المستودع العام.

## PDF

زر «تصدير PDF» يستخدم نفس DOM/CSS المعروض على الشاشة مع `@page A4`؛ لذلك يبقى النص نصًا حقيقيًا قابلًا للتحديد والبحث والنسخ. قبل فتح نافذة الحفظ/الطباعة يعمل فحص تجاوز الحدود؛ إذا كان عنصر أعرض أو أطول من المساحة المتاحة يُمنع التصدير ويُعلّم العنصر بدل إخراج PDF مقصوص.

## المعادلات الكيميائية

- اتجاه LTR مع عزل Unicode عن العربية RTL.
- معاملات التفاعل تبقى أرقامًا عادية قبل الصيغة.
- أعداد الذرات تتحول إلى subscript.
- التأكسد/الشحنة يمكن إدخاله بصيغة مثل `Fe^3+` فيظهر superscript.
- `-حرارة->` و`--حرارة-->` تضعان «حرارة» أعلى السهم.
- الأسهم النصية تُعرض كأسهم حقيقية مع الاحتفاظ بالمصدر الدلالي الأصلي.
- مثال: `3Fe + 2O2 -حرارة-> Fe3O4`.
- في سطر عربي يحتوي معادلة، يبقى الشرح RTL وتُعزل المعادلة وحدها LTR.

## الجداول

المحتوى المفصول بـ tabs أو pipes يتحول إلى `<table>` حقيقي. عند اللصق من محتوى HTML/Word يحاول التطبيق اكتشاف `<table>` وتحويله إلى خلايا قابلة للتحرير. يمكن إضافة وحذف الصفوف والأعمدة، تغيير عرض الأعمدة وارتفاع الصفوف، وتحرير الخلايا مباشرة.

## الصور

كل فقرة/سؤال/قائمة/ملاحظة تحصل افتراضيًا على إطار صورة واحد، مع إمكانية الوصول إلى 3 إطارات. الصور يمكن إضافتها وحذفها وإخفاؤها، وضعها يسار المحتوى أو أسفله، وتغيير حجمها من الإطار نفسه. عند الاتصال تُضغط الصور ثم تُرفع كملفات مستقلة بدل تضخيم JSON.

## الاختبارات

```bash
npm test
```

تغطي الاختبارات الحالية:

- عدم فقد أي حرف أثناء تقسيم النص.
- اكتشاف المعادلات وشروط التفاعل والأسهم.
- عدم قلب سطر الشرح العربي الذي يحتوي معادلة.
- حفظ المذكرة واسترجاعها ومشاركتها.
- رفع الصور واسترجاعها من مسار الأصول في وضع الخادم المحلي.

## النشر

يوجد `Dockerfile` جاهز لخدمات Node/Docker مثل Cloud Run. في بيئة إنتاج يجب استخدام HTTPS. إذا كانت المنصة ذات قرص مؤقت ففعّل Supabase بدل الاعتماد على `data/` المحلي.
